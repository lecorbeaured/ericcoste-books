# Eric Coste Books

Amazon-affiliate mini-site promoting Eric Coste's books (Amazon Associates tag: `ericcoste-20`).

- `index.html` — home hub
- `books/` — per-book sales pages (Hidden Laws of Money, AI Is Making People Money)
- `which-book.html` — 2-question quiz that recommends a book
- `articles/` — BOFU reading-list articles targeting "best AI books" search queries
- `sitemap.xml`, `robots.txt` — SEO

Static HTML/CSS, no build step. Deploy as-is on Vercel.
